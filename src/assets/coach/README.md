# Coach-Bilder

Eine PNG-Datei pro Stimmung, Dateiname = Stimmung (siehe unten).

**Format für alle Bilder gleich:**
- **512 × 512 px**, PNG mit **transparentem Hintergrund**
- gleicher Bildausschnitt bei allen (z. B. Kopf und Schultern, mittig),
  damit beim Wechsel nichts springt
- angezeigt wird der Coach ca. 64–96 px groß – Gesicht und Ausdruck
  müssen also auch klein gut lesbar sein

Fehlt ein Bild, nimmt die App automatisch `neutral.png`.
Fehlt auch das, wird kein Coach angezeigt.

| Datei | Wann |
|---|---|
| `neutral.png` | Start, Theoriezüge, nichts Besonderes |
| `happy.png` | guter / bester Zug von dir |
| `amazed.png` | brillanter oder starker Zug von dir |
| `thinking.png` | Ungenauigkeit, Engine rechnet, Zug wird geprüft |
| `worried.png` | Fehler von dir |
| `shocked.png` | Patzer von dir |
| `disappointed.png` | verpasste Chance von dir |
| `excited.png` | Gegner patzt – jetzt zuschlagen! |
| `explaining.png` | „Zeig mir, was passiert“, Tipp, Lösung |
| `celebrating.png` | Puzzle gelöst, Matt gesetzt, Partie gewonnen |
| `encouraging.png` | Puzzle falsch – „versuch's nochmal“ |
