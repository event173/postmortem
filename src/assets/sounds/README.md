# Eigene Sounds

Lege hier Dateien mit diesen Namen ab (Endung `.ogg`, `.mp3` oder `.wav`):

| Datei | Wann |
| --- | --- |
| `move` | normaler Zug |
| `check` | Schach |
| `checkmate` | Matt |
| `setup` | neues Brett wird aufgestellt (neue Partie, neues Puzzle, neue Eröffnungsvariante) |
| `capture` *(optional)* | Schlagzug – fehlt die Datei, wird `move` verwendet |

Tipps: keine Stille am Anfang, kurz (Zug/Schach 0,1–0,3 s, Aufstellen bis ~1 s),
alle etwa gleich laut, nicht übersteuert. `.ogg` läuft unter Linux und Windows sicher.

Fehlt eine Datei, nimmt die App ihren eingebauten (synthetischen) Holzklang.
